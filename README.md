# বাজার দর | BazarDor

> বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের বাজারদর এক নজরে।

BazarDor is a Bangla-first web app for exploring daily product prices,
comparing markets, and keeping up with price changes across Bangladesh.

## Technologies Used

- **Next.js** — App Router and server-rendered pages
- **TypeScript** — typed application code
- **Tailwind CSS** and **DaisyUI** — responsive design and UI components
- **Better Auth** — email/password and optional Google and GitHub sign-in
- **MongoDB** — authentication accounts and session storage
- **BazarDor API** — product, category, and market-price data

## Key Features

1. **Bangla-first responsive dashboard** with intuitive navigation and a live
   scrolling price ticker.
2. **Daily price highlights** showing products with the largest price increases
   and decreases.
3. **Product and category browsing** with price sorting and Bengali number
   formatting.
4. **Market price comparisons** with product details and prices by market.
5. **User accounts and profiles** with email/password registration, optional
   social sign-in, and profile updates.
